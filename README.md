# MEYLAN АВТО

Статический лендинг сервиса срочного выкупа автомобилей в Санкт-Петербурге и Ленинградской области.

## Состав проекта

- `index.html` — главная страница;
- `privacy.html` — политика конфиденциальности;
- `styles.css` — адаптивные стили;
- `script.js` — калькулятор предварительной оценки, маска телефона и интерфейсные сценарии;
- `assets/` — локальные изображения, логотип и иконки мессенджеров;
- `robots.txt` и метатеги `noindex` — запрет индексации демонстрационного сайта.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска сайт доступен по адресу `http://localhost:4173`.

## Ограничения статической версии

Калькулятор работает в браузере и показывает предварительный диапазон. Отправка заявки в CRM или на сервер пока не подключена: пользователь продолжает общение по телефону либо через Telegram/MAX.
