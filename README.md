# MEYLAN АВТО

Лендинг сервиса срочного выкупа автомобилей в Санкт-Петербурге и Ленинградской области. Форма заявок использует PHP на основном хостинге.

## Состав проекта

- `index.html` — главная страница;
- `index.php` — входная страница для PHP/nginx-хостинга: 301 с HTTP и www на основной HTTPS-домен, затем вывод `index.html`;
- `privacy.html` — политика конфиденциальности;
- `styles.css` — адаптивные стили;
- `script.js` — отправка заявки, маска телефона и интерфейсные сценарии;
- `assets/` — локальные изображения, логотип и иконки мессенджеров;
- `send-lead.php` — проверка формы и отправка заявки на почту заказчика;
- Основной домен открыт для индексации; демонстрация GitHub Pages в ветке `gh-pages` закрыта через `robots.txt` и метатеги `noindex`.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска сайт доступен по адресу `http://localhost:4173`.

## Основной хостинг

Сайт размещён на ROKMERE, каталог `/www/meylanavtovykup.ru`, PHP 8.3. Основной адрес — `https://meylanavtovykup.ru/`. Сертификат Let’s Encrypt покрывает домен и www, автопродление включено.

В каталог публикации входят `index.php`, `index.html`, `privacy.html`, `send-lead.php`, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml`, `.htaccess` и `assets/`. Установщики, архивы, `.git`, локальные зависимости и секреты не должны оставаться в публичном каталоге. На nginx редиректы главной обеспечивает `index.php`; на Apache дополнительно используется `.htaccess`.

Обработчик задаёт `no-reply@meylanavtovykup.ru` и в заголовке From, и в SMTP-конверте через фиксированный параметр `-f`. Это обязательно на ROKMERE: 17.11.2026 в PHP был настроен отправитель по умолчанию `u10033@rokmere.ru`, а SPF домена `rokmere.ru` запрещал любые отправки (`v=spf1 -all`). SPF домена MEYLAN разрешает сервер ROKMERE. Успех PHP `mail()` означает приём письма в очередь; фактическую доставку проверяют по почтовому журналу или полученному письму.

## Статическая демоверсия

GitHub Pages показывает статический интерфейс из `gh-pages`; PHP там не исполняется. Форма обращается к абсолютному HTTPS-адресу обработчика на основном хостинге. Доставка заявок требует доступности основного домена и почтовой службы хостинга. Калькулятор стоимости удалён.
